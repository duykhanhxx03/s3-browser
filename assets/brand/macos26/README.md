# macOS 26 icon source

These SVGs are prepared for Apple's Icon Composer workflow:

- `01-background.svg`: a flat, opaque 1024px background layer.
- `02-s3-glyph.svg`: a 1024px foreground layer with the S3 lettering converted to outlines.

Use Icon Composer to apply platform masks, Liquid Glass material, specular highlights, shadows, and appearance annotations.
